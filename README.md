# Isekai Legends

Isekai Legends is a Minecraft mod for Forge 1.20.1 that brings an isekai story to the game. It features monsters, dungeons, unions, powers, abilities, skills, and various origins like elves, wolf people, and demons. This mod aims to provide an immersive isekai experience within Minecraft, complete with unique fighting styles, weapons, and abilities inspired by popular isekai anime.

## Install

1. Download the latest version of Forge for Minecraft 1.20.1 from the official Forge website.
2. Install Forge by running the downloaded installer.
3. Launch Minecraft using the Forge profile.
4. Download the Isekai Legends mod from the GitHub repository or the EnderDevelopment marketplace.
5. Place the downloaded mod file into the `mods` folder in your Minecraft directory.
6. Launch Minecraft using the Forge profile to start playing with the Isekai Legends mod.

## Use

1. Launch Minecraft using the Forge profile.
2. Create a new world or load an existing one.
3. Explore the world and discover new monsters, dungeons, and origins.
4. Form unions with other players to gain access to powerful abilities and skills.
5. Equip unique weapons and activate special fighting styles to enhance your combat abilities.
6. Progress through the isekai story and unlock new powers and abilities.
